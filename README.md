# JS Exercise 集合 (js-ex01 ～ js-ex28)

各フォルダはブラウザと JavaScript の練習課題です。基本的に各課題は HTML ファイルと対応する JS ファイルを含み、ブラウザで該当 HTML を開いて動作を確認します。

使い方
- ターミナルまたは Finder で該当フォルダを開き、ブラウザで HTML を開く（例: js-ex25/25.html）。
- 開発者ツールのコンソールでエラーを確認すること。
